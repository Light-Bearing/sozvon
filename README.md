# Созвон

Видео и голос напрямую между устройствами. Без серверной части, без
аккаунтов, без оплаты.

Вы жмёте «Позвонить» и получаете ссылку. Кто по ней перешёл — тот в
разговоре. Ни вам, ни гостям регистрироваться не нужно нигде.

Звук и картинка идут между устройствами, мимо любых посредников.

## Состояние

Спроектировано, не реализовано. Проект лежит в
[docs/superpowers/specs/](docs/superpowers/specs/).

## Пробник сети

```
node tools/probe.mjs
```

Показывает, какой у вас NAT (встанет ли прямое соединение) и какие
публичные каналы для рукопожатия живы из вашей сети.

## Домашний экран

Страницу можно поставить на домашний экран телефона или в список
приложений на компьютере — как обычное приложение, без магазина
приложений для этого. Добавлены значок и файл-описание: как называть
приложение, какого цвета фон, как открывать — во весь экран или как
обычную вкладку. Значок — латунный номерок с дыркой для крючка, на
тёмном фоне, в цветах самого приложения.

Отдельно добавлен фоновый обработчик, который отвечает за повторное
открытие страницы без сети. Устроен на одном правиле: сначала спросить
сеть, и только если сети нет — достать заранее отложенное. Наоборот
было бы опасно: список общих адресов для встречи двух устройств рано
или поздно устареет, и если бы обработчик первым делом подсовывал
старый запас, приложение однажды начало бы молча биться в мёртвые
адреса, не имея возможности дозвониться, — и никто бы не понял почему.

## Выкладка на GitHub Pages

Добавлена настройка для автоматической сборки и выкладки: при заливке
изменений в основную ветку она сама прогоняет проверки, собирает
страницу и публикует. Общедоступный адрес появится отдельным шагом —
когда для проекта заведут общий склад кода на GitHub и включат в нём
показ страниц; в рамках этой работы это не делалось.

## Один файл: честный итог опыта

Кроме обычной сборки, есть отдельный способ собрать всё в один-
единственный файл — на случай, если приложение понадобится передать без
всякой выкладки, просто файлом. Собирается командой
`npm run build:single`, результат — `dist-single/index.html`. Программа
и оформление в нём лежат внутри одного файла; значок, файл-описание для
домашнего экрана и фоновый обработчик остаются отдельными файлами рядом
— это особенность инструмента сборки, а не недоделка. Шрифты страница
по-прежнему берёт из сети, так что по-настоящему самостоятельным такой
файл не становится: без интернета вместо задуманных шрифтов останется
обычный, системный.

Главное, что хотелось узнать, — заработает ли камера, если открыть
такой файл прямо с диска, без всякого сетевого адреса. Проверить это
вживую в этой работе не вышло. Инструмент, которым здесь показывают
страницу в браузере, либо не пускает к камере вовсе — из соображений
безопасности он не даёт её ни одной странице вообще, не только файлу с
диска, — либо показывает файл, открытый прямо с диска, неподвижной
картинкой, не выполняя программу внутри. Ни то, ни другое не позволяет
честно проверить именно этот случай.

Собранный файл стоит открыть двойным щелчком в обычном браузере на
компьютере и попробовать нажать «Позвонить»: так сразу станет видно,
спрашивает браузер разрешение на камеру или отказывает молча.
