# Созвон

Видео и голос напрямую между устройствами. Без серверной части, без
аккаунтов, без оплаты.

Вы жмёте «Позвонить» и получаете ссылку. Кто по ней перешёл — тот в
разговоре. Ни вам, ни гостям регистрироваться не нужно нигде.

**Ссылка работает как номерок в гардеробе**: ни имени, ни паспорта — у
кого она, тот и войдёт. Секрет комнаты живёт только в хвосте ссылки,
после решётки, и браузер такой хвост на сервер не отправляет. Поэтому
даже тот, кто раздаёт саму страницу, не знает, о чём и с кем вы говорите.

Звук и картинка идут между устройствами, мимо любых посредников.

## Состояние

Приложение собрано и работает. Звонок между двумя вкладками встаёт за
три секунды, 121 тест зелёный.

**Но главная проверка ещё не пройдена.** Настоящий звонок между двумя
устройствами — компьютером и телефоном на мобильном интернете — не
проводился. Пока он не состоялся и не продержался пару минут со звуком
и картинкой, версию нельзя считать проверенной: правда про то, как себя
ведут сети операторов, выясняется только так, и зелёные тесты этого не
заменяют.

## Чего пока нет

- **Демонстрации экрана** — отложена сознательно, до надёжного звонка.
- **Ручного обмена** — запасной путь на случай, когда недоступны все
  публичные каналы, написан и покрыт тестами, но экранов для него нет.
  Доводить до интерфейса стоит, только если живая проверка покажет, что
  он кому-то нужен.
- **Ретранслятора** — на случай, когда прямое соединение не встаёт с
  обеих сторон. Появится, если живая проверка покажет, что он нужен.
- **Закрепления участника** — нужно с пяти человек.

## Как это устроено

Рукопожатие едет сразу через три независимых семейства публичных
сервисов — торрент-трекеры, nostr-релеи и MQTT-брокеры. Чтобы
приложение замолчало, должны одновременно исчезнуть все три, а они
между собой никак не связаны.

С ростом числа участников приложение само опускает качество: вдвоём —
полное, втроём-вчетвером помельче, с пяти человек видео остаётся только
у говорящего, с девяти — голосовой режим. Звук получают все и всегда.

Замысел целиком — в [docs/superpowers/specs/](docs/superpowers/specs/).

## Известная особенность

С пяти участников камерой начинает распоряжаться приложение: картинку
шлёт только тот, кто говорит. Кнопка «Камера» при этом показывает **ваше
намерение**, а не то, идёт ли картинка прямо сейчас. То есть камера
может быть погашена, пока говорит кто-то другой, хотя кнопка включена.
Это осознанный размен: иначе кнопка мигала бы сама по себе несколько раз
в минуту.

## Проверка связи

Внутри приложения есть отдельный экран: он показывает, как вас видно
снаружи и какие каналы живы. Это единственное место, где приложение
говорит техническими словами.

То же самое из командной строки, точнее:

```
node tools/probe.mjs
```

Пробник опрашивает несколько STUN-серверов из одного сокета и потому
умеет отличить дружелюбный NAT от симметричного. Браузер так не умеет:
он схлопывает одинаковые ответы и вычищает пометки о локальном порте
ради приватности, поэтому встроенный экран в этом случае честно говорит
«не определить», а не гадает.

## Домашний экран

Страницу можно поставить на домашний экран телефона или в список
приложений на компьютере — как обычное приложение, без магазина. Значок
— латунный номерок с дыркой для крючка, в цветах самого приложения.

Фоновый обработчик устроен на одном правиле: **сначала спросить сеть, и
только если сети нет — достать отложенное**. Наоборот было бы опасно:
список публичных адресов рано или поздно устареет, застрянет в запасе
намертво, и приложение начало бы молча биться в мёртвые адреса, а никто
бы не понял почему.

## Шрифты лежат здесь же

Приложение не обращается к чужим серверам за шрифтами. Иначе Google
узнавал бы адрес каждого, кто открыл «Созвон», — для приложения,
сделанного ради приватности, это никуда не годится. Все три семейства
под лицензией OFL и лежат в `src/fonts/`; взяты только кириллица и
латиница.

## Один файл

Кроме обычной сборки есть способ собрать почти всё в один файл — на
случай, если приложение понадобится просто передать, без всякой выкладки:

```
npm run build:single
```

Результат — `dist-single/index.html`. Программа, оформление и шрифты
внутри; значок, описание для домашнего экрана и фоновый обработчик
остаются отдельными файлами рядом — особенность инструмента сборки, а не
недоделка.

**Заработает ли камера, если открыть такой файл прямо с диска, —
неизвестно.** Проверить это в разработке не вышло: доступный инструмент
показа страниц не даёт камеру ни одной странице вообще. Откройте файл
двойным щелчком в обычном браузере и нажмите «Позвонить» — сразу станет
видно, спрашивает браузер разрешение или отказывает молча.

## Разработка

```
npm install
npm test
npm run dev
```

`npm run dev` поднимает сервер, видимый и с других устройств в той же
сети. Но звонок оттуда не встанет: по `http` с чужого адреса браузер
камеру не даёт — нужен `https`, то есть выложенная версия.

## Выкладка

При заливке в основную ветку проверки и сборка проходят сами, и страница
публикуется на GitHub Pages.
