# Стенд из двух трансляторов адресов

Домашнюю сеть не перенастроить под опыт, а без симметричного NAT проверить
приёмы обхода негде. Здесь оба вида трансляторов поднимаются в контейнерах.

```
peer-a ── router-a ──┐              ┌── router-b ── peer-b
(обычный домашний)   ├── net0 ──────┤   (симметричный)
                     │ «интернет»   │
                     └──── stun ────┘
```

```
docker compose up -d
docker exec nat-peer-a node /lab/peer.mjs a <ширина веера> [up|around]
docker exec nat-peer-b node /lab/peer.mjs b
```

Обе стороны работают **одним сокетом** от начала до конца: транслятор
запоминает отображение по внутреннему порту, и второй сокет проверял бы
не то, что задумано.

## Что стенд уже показал

**Стена воспроизводится точно.** А за обычным NAT (порт снаружи один и тот
же для всех), Б за симметричным (новый порт на каждого получателя). Б пишет
А на известный адрес — пакет выброшен, потому что приходит с порта, на
который А не писал.

**Веер в лоб не работает, и причина не та, что ожидалась.** Пакет,
прилетевший на транслятор и там выброшенный, **всё равно заводит запись в
его таблице** — и занимает ровно ту пару адресов, которая нужна. Дальше:

- если веер раскрыть первым, стуки чужих пакетов сдвигают порт собеседника
  **за пределы веера** (замерено: порт 37193 сохранялся, пока А молчал, и
  уезжал, стоило А стукнуть);
- если сперва дать собеседнику постучать, его порт закрепляется — но его же
  выброшенные стуки занимают пару у нас, и наш транслятор выдаёт вееру
  **другой внешний порт**. Замерено: веер на нужный порт 45081 ушёл с
  порта 48039, тогда как Б всё это время стучал на 48841. Из 400 пакетов
  245 ушли с «не того» порта.

То есть на трансляторах поверх Linux — а это почти все домашние роутеры —
выброшенный пакет не бесплатен: он портит ровно то отображение, ради
которого всё затевалось.

**Не проверено:** веер с многих сокетов сразу. Если раскрывать его с
десятка сокетов, сдвиг портит отображение только одному из них. В браузере
это десяток RTCPeerConnection. Следующий опыт — этот.
